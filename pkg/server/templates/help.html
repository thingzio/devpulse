Getting started with DevPulse

Getting Started

  • Sign in — authenticate with your GitHub account
  • Install the GitHub App — after signing in, install the DevPulse GitHub App on the organizations whose repos you want to track. This grants DevPulse API access to import repository data. Signing in alone is not enough — the app must be installed separately.
  • Add repos — search for any public GitHub repository and add it to your dashboard
  • Wait for import — data imports run hourly, or your admin can trigger one manually
  • Explore — use the tabbed dashboard to view health, activity, velocity, quality, and community metrics

Dashboard Tabs

  • Health — bus factor, repository status, stars/forks trends, community profile
  • Activity — event trends, PR size distribution, forks vs activity, issue ratio
  • Velocity — lead time to merge, change failure rate, release cadence, downloads
  • Quality — PR review ratio, review latency, time to close, reputation scores
  • Community — contributor retention, momentum, first-time funnel, entity affiliations
  • Events — searchable event log with type, date, username, and entity filters
  • Insights — AI-generated observations and action items per repository

Search

  • org:name — scope the dashboard to all repos in an organization
  • repo:name — scope to a single repository
  • Click a repo name in the overview table to filter by that repo
  • Use the period selector to adjust the time range

Usage Limits

  • Free tier — 5 repos, 2,000 events per week
  • Pro tier — 25 repos, 20,000 events per week
  • Enterprise — 100 repos, 100,000 events per week
  • The usage banner on the dashboard shows your current consumption
  • When the weekly limit is reached, imports pause until the following week
  • Need more repos or events? Click "Request Upgrade" when you hit the limit, or email devpulse@thingz.io

Troubleshooting

  • Stuck in sign-in loop — visit /auth/reset to clear your session and try again
  • Repo shows "Pending" — data imports run hourly; newly added repos will populate after the next import
  • Charts empty after selecting a repo — ensure the period selector covers a range with imported data
  • Can't add a repo — only public repositories can be added; check spelling of org/repo
  • Import errors or "Bad credentials" — the DevPulse GitHub App must be installed on the organization that owns the repo. Signing in via GitHub OAuth is not enough — the app installation is a separate step that grants API access for data imports.

For all other issues and questions, contact devpulse@thingz.io
