DevPulse

Understand the health of any open source project at a glance. Track contributor trends, measure development velocity, and surface risks before they become problems.

Sign in with GitHub

How It Works

1 Install the GitHub App
2 Add repos to track
3 Explore trends and insights

Project Health

  • Bus factor & pony factor — identify single-contributor risks and measure how evenly work is distributed across the team
  • Repository status — stars, forks, open issues, primary language, and license at a glance
  • Stars & forks trends — daily counts with historical backfill to spot growth or decline
  • Community profile — check for README, contributing guide, code of conduct, and issue/PR templates

Activity & Velocity

  • Activity trends — monthly PRs, reviews, issues, comments, and forks visualized over time
  • PR size distribution — changes bucketed by S/M/L/XL to spot review bottlenecks
  • Lead time to merge — average days from PR creation to merge, tracked monthly
  • Release cadence — monthly release counts and download trends to gauge delivery rhythm

Quality

  • PR review ratio — PRs to reviews per month with trend line showing review culture health
  • Review latency — average hours from PR creation to first review, helping teams set SLAs
  • Time to close — average days to close issues, highlighting responsiveness
  • Change failure rate — bug issues near releases and revert PRs as a proxy for release stability

Community

  • Contributor retention — new vs. returning contributors per month to measure community stickiness
  • Contributor momentum — rolling active count with month-over-month delta
  • First-time contributor funnel — track newcomers from first comment to first PR to first merge
  • Entity affiliations — see which companies are contributing and drill down to individual developers

AI Insights

  • LLM-generated observations — AI-powered health analysis highlighting trends, risks, and opportunities per repo
  • Time to first response — hours to first review or comment, a key contributor experience metric
  • Issue open/close ratio — monthly opened vs. closed to detect growing backlogs
  • Contributor reputation — two-tier scoring with bot filtering to surface your most impactful contributors

Dashboard

  • Seven tabs — Health, Activity, Velocity, Quality, Community, Events, and Insights in one unified view
  • Interactive charts — lazy-loaded Chart.js visualizations with dark and light theme support
  • Search & filter — scope by organization, repository, entity, event type, and time period
  • Usage tracking — weekly event limits with per-repo breakdown so you always know your consumption
