Terms of Service

Please review and accept the following terms before using DevPulse.

1. Data Collection & Access

  • DevPulse collects and processes only data that is already publicly accessible via the GitHub API. No information is gathered that is not available to any user of github.com.
  • Data collected includes contribution event metadata (pull requests, issues, reviews, comments), repository metadata (stars, forks, language, license), releases, and public contributor profiles.
  • DevPulse does not access, read, or store source code. Only event metadata and repository statistics are imported.
  • Where private repositories are supported, access requires an explicit GitHub App installation with repository-level permissions granted by the repository owner. Even then, only the same event metadata is collected—never source code.

2. Authentication & Credentials

  • DevPulse authenticates you via the standard GitHub OAuth web flow. The OAuth token is used only during the sign-in process to verify your identity and is not stored.
  • Data imports use GitHub App installation tokens that are short-lived (1 hour), minted on-demand for each import run, and never persisted to disk or database.
  • Your dashboard session is maintained via an encrypted, HTTP-only cookie. No GitHub credentials, tokens, or secrets are stored by DevPulse at any time.

3. Data Storage & Use

  • Imported data is stored in our database and used solely to generate project health analytics and insights for your dashboard.
  • Your data is isolated from other users through row-level security. Other users cannot view your tracked repositories or analytics.
  • We do not sell, share, or distribute your data to third parties.

4. AI-Powered Features

  • DevPulse may send aggregated, non-identifying repository statistics to a third-party large language model provider (currently Anthropic) to generate AI-powered observations and action items.
  • No personally identifiable information, source code, or raw event data is included in these requests. Only pre-computed metrics and summary statistics are sent.
  • AI-generated insights are informational only and should not be treated as professional advice.

5. Your Controls

  • You can add or remove repositories from your dashboard at any time.
  • You can revoke DevPulse access by uninstalling the GitHub App from your organization or account settings.
  • You can sign out and clear your session at any time from the dashboard or via /auth/reset.
  • You may request deletion of all your data by contacting us. Upon account deletion, all associated data is permanently removed.

6. Usage Limits

  • Accounts are subject to limits on tracked repositories, imported events per week, and data retention.
  • When weekly limits are reached, data imports are paused until the following week.
  • Limits exist to keep a shared service responsive. They are not a paid tier — DevPulse is free to use and there is nothing to purchase. Adjustments are made case by case at no cost.
