Changelog

What's new in DevPulse

April 12, 2026

  • Contact support form on the Help page — signed-in users can send messages directly to the DevPulse team

April 11, 2026

  • Added Settings page with profile info, plan details, and theme selector
  • GitHub profile data (name, company, location, bio) now imported automatically
  • Improved landing page with beta pricing, onboarding hint, and social sharing previews

April 10, 2026

  • Repos now import immediately when added — no more waiting for the next scheduled run
  • Dashboard shows an importing badge with live progress while your repo loads
  • Faster imports — unchanged repos are automatically skipped, and tokens rotate on rate limits

April 9, 2026

  • Deep reputation scoring now runs inline during import instead of a separate job
  • Expanded Help page with per-tab panel descriptions and troubleshooting
  • Fixed sign-in issues caused by duplicate OAuth callbacks

April 8, 2026

  • Shared token pool across all tenants for better GitHub API rate limit utilization
  • PR size backfill now bounded to 90 days with early exit on rate limit
  • Ghost GitHub users (deleted accounts) no longer cause import errors

April 7, 2026

  • Improved mobile layout — responsive tables, full-width search, and cleaner nav
  • Rate-limited requests now show a friendly message instead of a raw error
  • Health Scorecard cards wrap properly on narrow screens

April 6, 2026

  • Weekly reporting — all charts now show weekly granularity for periods under 6 months
  • New dashboard split: Portfolio view (summary + repo list) and Analytics view (per-repo tabs)
  • User avatar menu with theme toggle (light, dark, system)
  • Added period presets from 2 weeks to 3 years

April 5, 2026

  • Improved entity normalization — Azure and Oracle Cloud Infrastructure aliases now recognized
  • Row-Level Security hardened with COALESCE guards and FORCE policies
  • Added database autovacuum lag monitoring

March 30, 2026

  • Insight caching — AI insights regenerate only after 7 days and 10% event change, reducing costs ~85%
  • Server-side response caching with 5-minute TTL for faster dashboard loads
  • PDF and CSV data export for Pro and Enterprise plans

March 23, 2026

  • AI-generated insights with action items for Starter plans and above
  • Health Scorecard with graded scores across demand, throughput, and responsiveness
  • Content Security Policy headers for improved browser security
